# UCBarkley report-template prototype

Open `index.html` directly in a browser. The prototype compares five report
styles using the same sample stay information:

1. Storybook
2. Care Card
3. Timeline Diary
4. Photo Journal
5. Warm Postcard

The prototype references private images from `apps/inference/ai-test` for local
preview only. It does not copy those images into this directory. If those local
images are unavailable, the layout still renders with empty image placeholders.

Use the top navigation to switch templates and **Print / PDF** to inspect a
printable version of the active template.
